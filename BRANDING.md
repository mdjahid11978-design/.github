# JAHID GitHub Branding Standard

## Purpose

Apply one recognizable JAHID presentation across repositories without changing the technical or legal identity of upstream projects.

## Visual header

Preferred README opening:

```html
<div align="center">

# PROJECT NAME

### PROJECT TAGLINE

**AI · AGENTS · ASSISTANTS · SYSTEMS · ENGINEERING**

[![Built by Jahid](https://img.shields.io/badge/BUILT%20BY-JAHID-f5a623)](https://github.com/mdjahid11978-design)
[![JAHIDS.AI](https://img.shields.io/badge/JAHIDS.AI-CANONICAL-111827)](https://github.com/mdjahid11978-design/jahids.ai)

</div>
```

The supplied Hermes-style screenshot is a visual reference only. Do not copy another project's logo, artwork, trademark, or branding.

## Identity cards

Use these cards when useful:

| Field | Value |
|---|---|
| Built by | Jahid |
| Platform | JAHIDS.AI |
| Status | Actual repository status |
| Language | Actual primary language |
| License | Actual repository license |
| Provenance | Original / Modified / Upstream / Fork / Experiment |

## Attribution language

### Original

`BUILT BY JAHID`

Use only when the repository's history supports an original-work claim.

### Modified or forked

`ADAPTED & MAINTAINED BY JAHID`

Keep upstream attribution and licensing.

### Upstream

`MAINTAINED BY JAHID · UPSTREAM ATTRIBUTION PRESERVED`

Do not replace upstream copyright or license text.

## JAHIDS.AI relationship

JAHIDS.AI is the canonical integration platform. A repository can participate in the platform without being owned by the platform. Record the exact relationship in `OWNERSHIP.md` or `PROVENANCE.md` when applicable.

## README requirements

Use the smallest useful set of sections:

- Overview
- Status
- Features
- Architecture
- AI / agents / skills / tools
- Installation
- Configuration
- Usage
- API / interfaces
- Project structure
- Security
- Testing
- Deployment
- Documentation
- Roadmap
- Contributing
- License
- Third-party attribution
- Ownership and provenance

## Truthfulness

Never convert a planned feature into an implemented claim. Never claim production validation without evidence. Never claim ownership of third-party code, models, datasets, documentation, trademarks, or assets merely because they appear in an account.
