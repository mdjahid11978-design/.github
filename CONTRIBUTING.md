# Contributing to Jahid Projects

Thank you for contributing.

## Before you start

- Read the repository README and local contribution rules.
- Preserve upstream licenses and notices for forks or imported projects.
- Never commit secrets, credentials or private data.
- Keep changes small, testable and reversible.

## Pull requests

Include:

- What changed
- Why it changed
- Tests run
- Security impact
- Compatibility impact
- Documentation impact

## JAHIDS.AI projects

Changes affecting agents, models, memory, tools, automation, security, governance or production deployment require the repository's applicable policy and review gates.

Branding does not change ownership or upstream licensing.
