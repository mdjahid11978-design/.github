## Review-required repositories

All other repositories are classified by the synchronizer as `UNKNOWN`, `FORK`, `ARCHIVE`, or `MODIFIED` until their provenance is reviewed. The automation may add `JAHID_REPOSITORY.md`, but it must not replace upstream legal files or rewrite upstream READMEs without explicit classification.

## Presentation classes

| Class | README label | Legal handling |
|---|---|---|
| ORIGINAL | BUILT BY JAHID | JAHID project terms apply to original material only |
| MODIFIED | ADAPTED & MAINTAINED BY JAHID | Preserve upstream terms and identify modifications |
| FORK | MAINTAINED BY JAHID · UPSTREAM ATTRIBUTION PRESERVED | Preserve upstream license, notices and authorship |
| ARCHIVE | ARCHIVED · JAHID REPOSITORY | Do not imply active development |
| UNKNOWN | JAHID REPOSITORY · PROVENANCE REVIEW REQUIRED | No ownership claim beyond repository administration |
